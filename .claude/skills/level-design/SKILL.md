# Level Design
1. Establish level role, player abilities, duration, and prerequisite knowledge.
2. State the goal, stakes, critical and optional paths, and emotional rhythm.
3. Map beats such as teach → practice → test → variation/payoff → exit; adapt to genre.
4. For each beat, specify player intent, space/obstacle, information, feedback, failure cost, and exit condition.
5. Include landmarks, sightlines, navigation aids, checkpoints, and accessibility.
6. Identify gameplay, art, audio, scripting, and QA dependencies.
7. Define a greybox test and questions for confusion, pacing, and viable strategies.
