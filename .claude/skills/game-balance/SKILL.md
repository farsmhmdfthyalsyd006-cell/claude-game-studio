# Game Balance
1. Establish intended experience, audience, session length, and system rules.
2. List tunable variables, units, bounds, dependencies, and desired player outcomes.
3. Build a transparent model or example calculation; show assumptions and avoid false precision.
4. Check early, typical, and extreme player paths for dominant strategies, grind, runaway leads, dead ends, and unrecoverable states.
5. Propose a small set of changes with predicted effects and risks.
6. Design a test matrix: variables, observations, and evidence that supports or rejects the hypothesis.
7. Recommend privacy-conscious instrumentation only when useful and appropriate.

Don't prescribe manipulative monetization or exploitative retention. Consider challenge and accessibility options. Label simulated values; never present invented metrics as real evidence.
