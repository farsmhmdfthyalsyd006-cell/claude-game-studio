# Game Modding
1. Confirm authorization, game/version, platform, and intended mod.
2. Prefer official mod kits, documented APIs, and tools with clear provenance.
3. Follow `docs/AUTHORIZED_WORK.md`; clarify authorization if scope is unclear.
4. Recommend a backup, version-controlled workspace, and isolated local test copy.
5. Document dependencies, install/uninstall, compatibility, and rollback.
6. Keep changes minimal and reversible; don't distribute content the user doesn't own.
7. Test offline or in a private environment the user controls.

Do not help bypass DRM, anti-cheat, access controls, or paid entitlements; create online cheats/bots; evade detection; or access services/data without permission. Offer an official API, permitted local mod, toy example, or standalone prototype instead.
