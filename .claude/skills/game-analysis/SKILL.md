# Game Analysis
1. State the analysis question, purpose, source, and authorization basis.
2. Define method: observation, user-provided footage, public documentation, controlled play, or permitted test build.
3. Separate observations from interpretation and recommendations; cite timestamps/screens/sources where available.
4. Analyze the player journey: goals, feedback, controls, pacing, choices, accessibility, and friction.
5. Compare against the user's goals; don't claim one game's choices are universally optimal.
6. Present findings by impact and confidence with alternatives and validation questions.

Don't help defeat protections, extract proprietary assets/source, access private services, or gain unfair online advantage. If evidence is insufficient, say so and suggest a permitted way to gather it.
