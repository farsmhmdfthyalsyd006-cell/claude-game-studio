# Production Planning
1. Establish capacity, target platform, deadline constraints, project stage, and milestone outcome.
2. Define exit criteria as demonstrable outcomes, not activity lists.
3. Break work into reviewable tasks with roles, dependencies, estimate ranges, and acceptance criteria.
4. Identify critical path, external dependencies, unknowns, and risks; test high-impact unknowns early.
5. Protect a vertical slice and validation time; separate must-have, optional, and cut candidates.
6. For scope changes, show the trade-off: time, quality, risk, or what moves out.
7. Use `templates/PRODUCTION_PLAN.md`; keep assumptions explicit.

Estimates are hypotheses, not promises. Don't assign work to unavailable people or treat a generated plan as a commitment.
