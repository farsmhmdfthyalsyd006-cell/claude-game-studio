# Game Audio
1. Review genre, camera, platform, tone, loop, and accessibility requirements.
2. Define audio priorities: gameplay cues, ambience, music, UI, and voice.
3. Map events: trigger, intent, priority, variation, cooldown, mix behavior, and fallback.
4. For adaptive music, specify states, transitions, stingers, and pause/interruption behavior.
5. Brief assets with duration, context, loop points, mix relationships, format, naming, and provenance.
6. Consider captions, visual equivalents for critical cues, independent volume controls, and hearing safety.
7. Propose focused validation.

Never imply audio was produced, mixed, or tested unless it was.
