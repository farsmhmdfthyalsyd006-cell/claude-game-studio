# Art Direction
1. Review pillars, platform, camera, readability needs, audience, and production constraints.
2. Define visual principles: shape language, palette, materials, lighting, composition, motion, and contrast.
3. Explain how art supports play: silhouettes, interactable readability, threat hierarchy, and UI separation.
4. Create asset briefs with purpose, views/states, scale, variants, technical constraints, and acceptance criteria.
5. Describe what to learn from references; don't copy protected work.
6. Flag accessibility: color-independent cues, legibility, flashing effects, and motion settings.
7. Provide a validation checklist and production risks.

Don't claim to have generated or inspected assets unless true. Prefer original, properly licensed, traceable assets.
